# Klauda Lab Simulated Membranes Guide

This repository is a starting point for students learning how membrane simulations are designed, built, run, and analyzed in the Klauda Lab workflow.

## Start here

- [Getting Started](docs/getting-started.md) - Begin here for the goals of the guide, the major concepts, and how to use the rest of this repository.
- [Membrane Simulation Workflow](docs/workflow.md) - Follow the end-to-end process from planning a system to analyzing the results.
- [Simulation Types](docs/simulation-types.md) - Compare coarse-grained and atomistic simulations, plus symmetric and asymmetric bilayers.
- [Analysis Guide](docs/analysis.md) - Review common analysis questions and where analysis fits into the workflow.

## How to use this guide

1. Read [Getting Started](docs/getting-started.md) for the big-picture overview.
2. Move to the [Membrane Simulation Workflow](docs/workflow.md) when you are ready to plan and execute a project.
3. Use [Simulation Types](docs/simulation-types.md) when choosing the right model for a system.
4. Refer to the [Analysis Guide](docs/analysis.md) when interpreting completed simulations.

## Recommended navigation by task

- If you are new to membrane simulations, start with [Getting Started](docs/getting-started.md).
- If you are building a project, go directly to [Membrane Simulation Workflow](docs/workflow.md).
- If you need help deciding between modeling approaches, open [Simulation Types](docs/simulation-types.md).
- If you already have trajectories and need to interpret them, use [Analysis Guide](docs/analysis.md).

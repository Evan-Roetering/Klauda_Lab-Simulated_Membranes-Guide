# Klauda Lab Simulated Membranes Guide

This repository is meant to be a usage guide and storage space for my scripts that help with cluster usage, bilayer building, GROMACS simulation chains with Slurm, and analysis of large bilayer systems.

## Walkthroughs and Guides

- [WSL and SSH Setup](docs/zaratan-setup.md) - Setup and scripts for connecting to the [Zaratan High Performance Computing Cluster](https://hpcc.umd.edu/home/clusters/zaratan/) and [Ubuntu for WSL](https://ubuntu.com/wsl).
- [All-Atom Bilayers](docs/aa-bilayers.md) - Constructing all-atom bilayers using [CHARMM-GUI](https://charmm-gui.org/) and simulating them with [GROMACS](https://www.gromacs.org/)
- [Coarse-Grained Bilayers](docs/cg-bilayers.md) - Constructing coarse-grained bilayers with [Insane](https://github.com/Tsjerk/Insane) and simulating with [GROMACS](https://www.gromacs.org/)
- [VMD Usage](docs/vmd.md) - Visualize molecular systems with [Visual Molecular Dynamics (VMD)](https://www.ks.uiuc.edu/Research/vmd/)
- [Python Tools for CG Systems](docs/cg-analysis-tools.md) - Python scripts useful for the analysis of large undulating CG systems

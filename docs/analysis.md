# Analysis Guide

Analysis is where simulation output is translated into scientific conclusions.

## Common analysis goals

- Evaluate whether the membrane has equilibrated
- Compare structural and dynamical properties across systems
- Relate composition to emergent membrane behavior
- Identify which measurements answer the original scientific question

# Getting Started

This guide is intended to help students understand both the scientific context and the practical workflow behind simulated membrane systems.

## What this repository covers

- Basic orientation to membrane simulation projects
- How the Klauda Lab workflow moves from design to analysis
- Where coarse-grained and atomistic methods are most useful
- How to connect simulation setup decisions to downstream analysis

## Suggested reading order

1. Return to the [README](../README.md) for the main navigation page.
2. Continue to the [Membrane Simulation Workflow](workflow.md) for the full process.
3. Read [Simulation Types](simulation-types.md) to understand common modeling choices.
4. Use the [Analysis Guide](analysis.md) when reviewing results.

## When to use each section

- Use [Membrane Simulation Workflow](workflow.md) when you need procedural guidance.
- Use [Simulation Types](simulation-types.md) when comparing approaches.
- Use [Analysis Guide](analysis.md) when planning measurements or interpreting output.
